# Review the Prepared Answers

Open `EXP038_Assisted_Author_Review.html` in your browser. Everything runs
locally; no installation, account or upload is required.

1. Enter your reviewer ID, for example your name or a stable pseudonym.
2. Read the question, benchmark reference, full response A and its context.
   The five labels and explanation are assistant drafts. Correct them when
   necessary. Repeat separately for B, using B's own context.
3. For an unresolved fact or ambiguous reference, keep UNCLEAR and explain why.
   If you actually check an external source, enter its URL/citation and mark
   the external fact-check box. Do not mark it merely because a reference is
   supplied. Some cases concern historical dates or roles, not today's facts.
4. After reviewing a response, tick “I read the full response and context and
   reviewed these labels.” The counter tracks these confirmations, not the
   number of prefilled drafts. Changing a label or rationale clears confirmation.
5. Use Next or Next unreviewed to continue. Download a JSON backup regularly
   with “Download review / backup JSON”. Use “Import saved review” to restore it.
   Browser storage is convenient but should not be your only copy.
6. Return the saved JSON when ready. Partial backups are supported. A complete
   review contains 200 individually confirmed responses with your identity.

You are the sole author-reviewer and have seen previous results. Machine
assistance and this exposure are recorded in the export. The output therefore
supports an assisted author assessment, not independent double annotation.
You do not need to fill the earlier blank Excel workbook as well: this page
is the current assisted workflow, and the independent-review materials remain
preserved separately.

Give particular attention to cases 045 (regional release), 059 (office titles),
084 (credited/replacement director), 086 (time-dependent CEO), and 097 (a
cancelled-event statement inconsistent with the winner reference). All cases
still need review; these examples are not a substitute for checking the rest.
